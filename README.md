# HomeFind React Frontend

A responsive React + Vite frontend recreated from the supplied HomeFind real-estate landing-page reference.

## Requirements
- Node.js 18+ (recommended)

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Build
```bash
npm run build
npm run preview
```

## Included interactions
- Buy / Rent / Sold tabs
- Location search and property filtering
- Bedrooms and maximum-price filters
- Save / unsave properties
- Property detail demo notices
- Responsive navigation on mobile

Property photos are loaded from Unsplash, so an internet connection is required for the images. This is a frontend demo; sign-in, advertising, and real property data are not connected to a backend.
